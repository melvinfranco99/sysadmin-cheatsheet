Conectar con GitHub

Los cambios se guardan primero en este navegador. Para que aparezcan también en GitHub y en la web publicada, conecta un token de acceso personal.

Crea uno en github.com/settings/tokens?type=beta, limitado solo a este repositorio, con permiso "Contents: Read and write". Se guarda únicamente en este navegador (localStorage) — usa "Olvidar token" si compartes el equipo.
